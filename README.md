# 🎵 Spotify Clone

A responsive Spotify-inspired music streaming interface built as a frontend development project.

## ✨ Features

* 🎵 Music-focused user interface
* 🎧 Playlist sections
* 🎚️ Music player interface
* 📱 Responsive layout
* 🎨 Spotify-inspired design
* 🖥️ Clean and reusable HTML/CSS structure

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Kashiish134/spotify-clone.git
```

Open the project directory:

```bash
cd spotify-clone
```

Then open `index.html` in your browser.
